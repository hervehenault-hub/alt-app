# Alt.

Application mobile qui aide à trouver, près de chez soi, des alternatives écologiques
(vrac, réparation, réemploi, anti-gaspi, producteurs locaux). Ville pilote : Bordeaux.

- Démarrer : `pnpm install`, puis `cd apps/mobile && cp .env.example .env && pnpm start`.
- Règles du dépôt et commandes : [`CLAUDE.md`](CLAUDE.md).
- Architecture : [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).
